# Información legal de C-Gest

Política de privacidad y condiciones de uso de **C-Gest**, la aplicación de
gestión para comunidades de propietarios.

Estas páginas están publicadas porque Google Play y la App Store exigen una URL
pública de política de privacidad, y tiene que seguir en pie mientras la
aplicación exista.

Los textos se escriben en Markdown (`privacidad.md`, `terminos.md`) y las
páginas se generan con `node construir.mjs`. El correo de contacto está en un
solo sitio, al principio de ese guion.
